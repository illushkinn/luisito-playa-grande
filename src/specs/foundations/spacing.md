# Spacing Foundation — Luisito Playa Grande

## 8-Step Scale

| Token | Rem | PX | Usage |
|-------|-----|-----|-------|
| `--space-xs` | 0.25rem | 4px | Tiny gaps, padding on small elements |
| `--space-sm` | 0.5rem | 8px | Small gaps, button padding |
| `--space-md` | 1rem | 16px | Standard gap, card padding |
| `--space-lg` | 2rem | 32px | Section spacing |
| `--space-xl` | 4rem | 64px | Large section spacing |
